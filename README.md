# Psykin

Minimal static website for [psykin.co](https://psykin.co), deployed with GitHub Pages.

## Structure

- `index.html` — homepage
- `404.html` — custom not-found page
- `assets/css/styles.css` — global styles
- `assets/js/main.js` — lightweight client-side behavior
- `CNAME` — GitHub Pages custom-domain mapping
- `.nojekyll` — serves the site as plain static files

Publishing is configured from the repository's default branch root. Changes pushed to that branch are deployed automatically by GitHub Pages.
